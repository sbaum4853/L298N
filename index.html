Recap · Last lesson in one slideWorksheet · Checkpoint 1

Same wave, new job

PWM = switching fully ON and fully OFF, very fast. The percent of time it's ON is the duty cycle.

Your eye couldn't keep up with the LED's blinking, so it saw the average: "dim."

A motor can't keep up either. It's heavy, so it can't stop and start hundreds of times a second. It settles at an in-between speed.

Step 2 · Power plan for todayWorksheet · Checkpoint 3

Two jobs: a brain and some muscle

Brain power: your laptop powers the Arduino through USB.

Muscle power: the 12 V pack powers the motors through the L298N.

Rule 1. Grounds are connected. HIGH means "5 V above ground." If the L298N and the Arduino don't share a ground, the L298N can't tell what HIGH is.
Rule 2. 12 V never touches the breadboard or the Arduino's 5V pin. 12 V into a 5 V pin = a dead Arduino.
Rule 3. Battery OFF while you wire. It goes on after your teacher checks your wiring.

Why not run the motors from the Arduino? A USB port gives about 0.5 amps. Two motors starting at once can pull more than that and reset your Arduino.

Step 3 · Build A · MotorsNEW: highlighted

Motors into the screw terminals

  1. Loosen the screws on OUT1 and OUT2 (counter-clockwise, 2–3 turns).
  2. Put Motor A's two wires into OUT1 and OUT2. Tighten.
  3. Tug test. A wire that pulls out today will pull out on the car.
  4. Motor B's wires go into OUT3 and OUT4. Tighten and tug.
  5. Mark Motor A with tape or marker: A (left).
Don't worry about which wire goes in which hole. If a motor spins backward, you'll fix it on slide 9.
Step 3 · Build B · Battery and groundNEW: highlighted

Battery in, grounds together

  1. Battery pack OFF (or leave one AA out).
  2. Battery red → +12V terminal. Battery black → GND terminal.
  3. A male-to-male jumper goes into the same GND terminal. Its other end goes in the breadboard's − rail.
  4. Arduino GND → the same − rail.
  5. +5V terminal: leave it empty. 5V-EN jumper: leave it on.
Two wires in one screw terminal: put both in, then tighten. Tug-test both.
That − rail is now the common ground from slide 5.

Step 4 · Test 1 · DirectionWorksheet · Checkpoint 5

Which way is forward?

  1. Plug in USB. Copy the code, paste, upload.
  2. Battery ON.
  3. Hold the motors the way they'll sit on the car: Motor A on the left, Motor B on the right, shafts pointing out. Put a tape flag on each shaft.
  4. During FORWARD, the tops of both shafts should roll away from you.
A motor going the wrong way? Battery OFF, swap that motor's two wires in its screw terminal. Don't change the code. That way everyone's car runs the same code.
Notice: IN1/IN2 pick the direction. ENA picks the speed.
// Test 1: direction check
const int ENA = 5;  const int IN1 = 7;  const int IN2 = 8;   // Motor A (left)
const int ENB = 6;  const int IN3 = 9;  const int IN4 = 10;  // Motor B (right)

void setup() {
  pinMode(ENA, OUTPUT);  pinMode(IN1, OUTPUT);  pinMode(IN2, OUTPUT);
  pinMode(ENB, OUTPUT);  pinMode(IN3, OUTPUT);  pinMode(IN4, OUTPUT);
}

void loop() {
  // FORWARD for 2 seconds
  digitalWrite(IN1, HIGH);  digitalWrite(IN2, LOW);
  digitalWrite(IN3, HIGH);  digitalWrite(IN4, LOW);
  analogWrite(ENA, 150);    analogWrite(ENB, 150);
  delay(2000);
  // STOP for 1 second
  analogWrite(ENA, 0);  analogWrite(ENB, 0);  delay(1000);
  // BACKWARD for 2 seconds
  digitalWrite(IN1, LOW);   digitalWrite(IN2, HIGH);
  digitalWrite(IN3, LOW);   digitalWrite(IN4, HIGH);
  analogWrite(ENA, 150);    analogWrite(ENB, 150);
  delay(2000);
  // STOP for 1 second
  analogWrite(ENA, 0);  analogWrite(ENB, 0);  delay(1000);
}

// Test 2: PWM by hand, Motor A only
const int ENA = 5;  const int IN1 = 7;  const int IN2 = 8;

int onTime  = 200;   // ms with power
int offTime = 200;   // ms with no power

void setup() {
  pinMode(ENA, OUTPUT);  pinMode(IN1, OUTPUT);  pinMode(IN2, OUTPUT);
  digitalWrite(IN1, HIGH);  digitalWrite(IN2, LOW);   // forward
}

void loop() {
  digitalWrite(ENA, HIGH);   // ON
  delay(onTime);
  digitalWrite(ENA, LOW);    // OFF
  delay(offTime);
}

Step 6 · analogWrite does it for youWorksheet · Checkpoint 7

analogWrite = PWM by hand, 980 times a second

Your smoothest test, 2 / 2, pulsed 250 times a second. analogWrite on pin 5 or 6 pulses about 980 times a second. That's why it's silky smooth.

The L298N uses up about 2 V, so at 255 the motor gets about 10 V. Duty cycle sets the average:

average V ≈ 10 V × (value ÷ 255)

Speed limit: TT motors are built for about 3–6 V. Short bursts at 255 are fine. For long runs, keep the car around 150 or less (about 6 V).
analogWrite(ENA, 128) → duty 50% → about 5.0 V average

// Test 3: the speed knob
const int ENA = 5;  const int IN1 = 7;  const int IN2 = 8;   // Motor A
const int ENB = 6;  const int IN3 = 9;  const int IN4 = 10;  // Motor B
const int KNOB = A0;

void setup() {
  pinMode(ENA, OUTPUT);  pinMode(IN1, OUTPUT);  pinMode(IN2, OUTPUT);
  pinMode(ENB, OUTPUT);  pinMode(IN3, OUTPUT);  pinMode(IN4, OUTPUT);
  Serial.begin(9600);

  digitalWrite(IN1, HIGH);  digitalWrite(IN2, LOW);   // Motor A forward
  digitalWrite(IN3, HIGH);  digitalWrite(IN4, LOW);   // Motor B forward
}

void loop() {
  int knob  = analogRead(KNOB);   // 0 to 1023
  int speed = knob / 4;           // 0 to 255

  analogWrite(ENA, speed);
  analogWrite(ENB, speed);

  Serial.println(speed);
  delay(50);
}
Step 8 · The starting lineWorksheet · Checkpoint 8

How slow can your motor go?

  1. Knob all the way down (0). Now turn it up very slowly, watching Serial Monitor.
  2. The number where the wheels first start turning = START.
  3. Turn it up a little more, then turn it down slowly. The number where they stop = STOP.
  4. Listen: set the knob just below START. Put your ear near a motor. That sound is pin 5 switching on and off about 980 times a second. Your eye couldn't catch the LED's blink. Your ear can catch the motor's.
Why it matters on the car: any speed below START just sits there humming. Your slowest useful speed is about START.

One function for every move

drive(left, right) takes a speed for each wheel. Negative = backward.

abs() turns −150 into 150, because analogWrite only takes 0–255.

// Bonus: one function for every move
void drive(int left, int right) {
  // Motor A (left)
  if (left >= 0) { digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);  }
  else           { digitalWrite(IN1, LOW);  digitalWrite(IN2, HIGH); }
  analogWrite(ENA, abs(left));

  // Motor B (right)
  if (right >= 0) { digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);  }
  else            { digitalWrite(IN3, LOW);  digitalWrite(IN4, HIGH); }
  analogWrite(ENB, abs(right));
}

void loop() {
  drive(150, 150);    delay(1500);   // straight
  drive(150, 90);     delay(1500);   // gentle right
  drive(150, 0);      delay(1000);   // pivot right
  drive(-150, 150);   delay(800);    // spin left
  drive(-150, -150);  delay(1500);   // backward
  drive(0, 0);        delay(2000);   // stop
}
